Bem-vindo ao repositório da **Best Car Agency**, uma landing page moderna de alta performance desenvolvida para proporcionar uma experiência imersiva no mundo automotivo.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as melhores ferramentas do ecossistema front-end:

* **React.js**: Biblioteca principal para interfaces de usuário.
* **Vite**: Build tool ultrarrápida para desenvolvimento moderno.
* **Tailwind CSS**: Estilização baseada em utilitários para design responsivo.
* **TypeScript**: Tipagem estática para um código mais seguro e robusto.
* **Framer Motion**: (Opcional) Animações fluidas de entrada e interatividade.

---

## 🎨 Funcionalidades Principais

* ✅ **Hero Section Animada**: Carro com efeito de movimento e suspensão.
* ✅ **Design Responsivo**: Adaptado para Desktop, Tablet e Mobile.
* ✅ **Performance**: Otimização de imagens e carregamento rápido via Vite.
* ✅ **Clean Code**: Estrutura de componentes organizada e escalável.

## 🚀 Como rodar o projeto localmente

Se você quiser clonar este projeto e testar na sua máquina:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/ErikMartinsss-hub/best-car-agency.git](https://github.com/ErikMartinsss-hub/best-car-agency.git)
    ```
2.  **Entre na pasta:**
    ```bash
    cd best-car-agency
    ```
3.  **Instale as dependências:**
    ```bash
    npm install
    ```
4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```
